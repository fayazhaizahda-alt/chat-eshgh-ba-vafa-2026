# برنامه اندرویدی «شعر»

این پوشه پروژه Android برنامه مستقل «شعر» را نگه می‌دارد.

- شناسه برنامه: `com.fayazhaizahda.shear`
- صفحه شروع: https://fayazhaizahda-alt.github.io/chat-eshgh-ba-vafa-2026/shear/
- دکمه اتاق چت، چت عشق با وفا را در همان برنامه باز می‌کند.
- گردش‌کار GitHub Actions فایل آزمایشی APK و بسته AAB انتشار را می‌سازد.

برای انتشار واقعی در Google Play، بسته AAB باید با کلید امضای امن مالک برنامه امضا شود و از طریق حساب Play Console بارگذاری گردد.
